# Numera — фабрика чисел (Android)

Прототип самостоятельной Android-игры, вдохновлённой механиками числовых фабрик: источники чисел, ленты, вычислительные машины, центральный узел и постепенные цели.

**Визуальный стиль:** тёмный графитово-синий фон, мягкая сетка, бирюзовые анимированные конвейеры, янтарные цифровые капсулы, фиолетовые сумматоры и синие умножители. Интерфейс ориентирован на касание и небольшой экран; собственного кода и графики достаточно без сторонних игровых ассетов.

**Состояние:** исходники Android-прототипа. APK зависит от успешной сборки GitHub Actions, успешная установка на устройство пока не подтверждена.

Управление: нижняя панель выбирает ленту, источник, сложение, умножение, удаление или перемещение камеры. Повторное касание конвейера поворачивает его. Протягивание в режиме ленты строит последовательность лент. В режиме камеры — движение одним пальцем, масштаб — двумя. Прогресс сохраняется локально.
