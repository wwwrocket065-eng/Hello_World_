GlassStudy v0.2.11 release hardening (2026-10-17)

User's Google Play Protect reported v0.2.10 as harmful and Android refused installation. Cause not definitively determined from screenshot. This build removes REQUEST_INSTALL_PACKAGES, APK background downloader, FileProvider, and Android's unknown-sources permission flow, to reduce attack surface. It retains background `.pupdate` data-only updates with RSA signature+SHA256 verification, transactional staging and rollback. Native APK updates must use a trusted distribution channel (e.g. Google Play); no bypass of Play Protect. Same application ID and original APK signing certificate must be preserved. Compile CI, verify final signature, inspect permissions, then test Play Protect and on-device startup before calling release safe.
