# GlassStudy v0.2.20 — стиль интерфейса v0.1.22, иконка с бокалом

По просьбе пользователя:
- Верхняя панель: фирменный ромб, название GlassStudy, подпись 3D LAB и четыре скруглённых квадратных кнопки (объекты, свет, сброс камеры, меню). Раскладка основана на первой согласованной иллюстрации.
- Нижняя панель: две выпадающие кнопки выбора стакана/LOD, рядом Свет/Камера и Сетка, ниже Экспорт сцены и Диагностика; отдельная кнопка «Применить» полностью удалена.
- Выбор модели/LOD теперь немедленно загружает GLB из существующего подписанного менеджера; обработчик выбора подключён после начальной инициализации, чтобы избежать повторной загрузки.
- Дизайн из исходников v0.1.22: фон графит #07111d, тёмно-синие кнопки #10273b/#173043, бирюзовый контур #6ad8db, полупрозрачные панели, плавные углы, светлый текст.
- Иконка приложения: выбранная ПОЛЬЗОВАТЕЛЕМ ВТОРАЯ генерация — циановый ромб за стеклянным бокалом. Android launcher drawable WebP 192×192; исходная картинка сохранена в ChatGPT.
- APK label изменён на GlassStudy 3D LAB, package name, apk certificate, target/min SDK и все механизмы .pupdate сохранены.
- Рендер, GLB, камера, диагностика CPU/RAM, статус patched version, rollback, проверка RSA, кнопки экспорта — не удалены.
- Прежние UI patch JSON (вплоть до 20023) принимаются с безопасными defaults и рестайлят новые кнопки, но физическая раскладка фиксирована новой версией и не заменяется старым порядком topOrder.
- Сборка CI и подпись не заменяют проверки на телефоне.
