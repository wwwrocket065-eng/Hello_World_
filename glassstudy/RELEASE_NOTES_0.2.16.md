# GlassStudy v0.2.16 — полная русская диагностика

Переведены все подписи и пояснения в окне диагностики, включая строку устройства, отрисовки, ресурсы, подпись материала стекла, карту окружения и трассировку лучей. Технические имена Filament, gltfio, IOR и IBL оставлены узнаваемыми.

Диагностические подписи теперь читаются из ui/layout.json, то есть могут обновляться через существующий подписанный .pupdate, без изменения Kotlin. Схема ограничена известными диагностическими ключами: неподписанный или неподдерживаемый патч отклоняется. Встроенный русский словарь используется при отсутствии подписанных переводов в старых патчах.

Номер приложения берётся из BuildConfig, установленный патч и подтверждённый патч — из PatchManager. Подключение к серверу, офлайн-откат, установка подписанных патчей из «Загрузок» и ключ APK сохранены.

Проверка: после установки APK 0.2.16 опубликованный UI-патч 20019 меняет подпись кнопки на «Диагностика RU» и обновляет заголовок отчёта. В диагностике должны быть: «Установленный патч ресурсов: 20019», «Патч, подтверждённый отрисовкой: 20019», «Патч на сервере: 20019».
