# GlassStudy 0.2.17 · компактная аппаратная диагностика

- Убрана повторяющаяся строка версии приложения. Все три версии патча сведены в одну строку.
- Добавлены: интервал кадра (средний и P95 по 180 кадрам), приблизительный FPS по этим интервалам, wall-clock длительность подготовки/подачи кадра в UI-потоке, CPU-время приложения за ~1 секунду (в % одного ядра; может быть >100%), PSS приложения, Java/native heap, свободная/общая память устройства.
- Добавлены реальные числа вершин/треугольников/примитивов (согласно атрибутам выбранного GLB), размер файла и первые 12 символов SHA256.
- Добавлены дистанция, азимут/наклон камеры, параметры направления и яркости света, DPR, наличие IBL и статус отсутствующего финального path tracing.
- GPU load и GPU timer не выдумываются; в native beta не реализовано измерение. FPS — pacing Choreographer, а не время GPU.
- Порядок и видимость разделов diagnosticSections с allowlist из 7 имен и переводы любых labels diagnostics находятся в подписанном UI JSON, и будут обновляться через .pupdate без APK.
- Если активен старый UI-патч 20019, новые метрики и русские разделы используют безопасные встроенные defaults; существующие патчи моделей копируются вперед.
- Старые автоматическая проверка, установка через «Загрузки», RSA-подпись, SHA256, откат и подтверждение кадром неизменны.
- Совместимость app ID/сертификата сохраняется. Сборка GitHub CI и тесты не заменяют запуск на физическом телефоне.
- Для тестирования конфигурации разделов — signed UI-only .pupdate 20020, затем сверка Diagnostics installed/confirmed/server.
