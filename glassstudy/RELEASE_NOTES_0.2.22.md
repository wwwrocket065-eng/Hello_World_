# GlassStudy v0.2.22

Главное: горизонтальное вращение объекта инвертировано по просьбе пользователя.
- При перетаскивании вправо угол yaw теперь уменьшается вместо увеличения.
- Вертикальная ось, вращение света и скорость приближения/отдаления неизменны.
- Параметр `invertHorizontal` включён по умолчанию в исходном UI JSON и имеет
  fallback `true` для старых установленных signed UI patches (включая v20022/20023).
- Любой следующий подписанный `.pupdate` с `ui/layout.json` может переключить
  `invertHorizontal` true/false без переустановки APK.
- Динамическое добавление/удаление, порядок, оформление, подписи кнопок и векторные
  иконки с чипом в верхнем левом положении включены из v0.2.21.
- Новых Android разрешений нет. ID приложения, APK certificate, patch RSA key,
  проверка SHA256/rollback, модели и Filament без изменений.
- Проверка CI/подписи не заменяет физический Android тест.
