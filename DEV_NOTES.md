# Downloads 1.0.0
Independent Android download manager, package local.downloads.app. Own private file storage and durable index. HTTPS direct file URLs, Android Share intent, sequential queue, foreground service, progress, pause/resume with server range validation, copy to public Downloads on explicit export, read-only URI sharing. No access to Konsilium or other apps' private files. Server must support Range and validators for safe continuation; otherwise restarts. No browser/login/cookie capture. Release key backup: Library /Downloads/private-signing/Downloads-signing-backup.zip. Certificate SHA-256: 4b0ed62f4f15255f05ea5f10bff9564e1e989789570b0813e18f81bdfb6fe9e7. Never generate another key for updates. CI builds unsigned; verify signature before release.

Project folders are physical app-private directories keyed by stable IDs. Choose destination before download or shared file import; move completed files. Direct HTTPS file downloads have no extension or app-defined size limit; server/authentication and disk space still matter. Optional downloads://add?url=ENCODED_URL&folder=ENCODED_FOLDER preselects existing folder; explicit user action is required to start. Android share accepts links and content URIs. ChatGPT cannot remotely control the app by itself.
