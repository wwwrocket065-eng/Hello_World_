# Downloads 1.0.0
Independent Android download manager, package local.downloads.app. Own private file storage and durable index. HTTPS direct file URLs, Android Share intent, sequential queue, foreground service, progress, pause/resume with server range validation, copy to public Downloads on explicit export, read-only URI sharing. No access to Konsilium or other apps' private files. Server must support Range and validators for safe continuation; otherwise restarts. No browser/login/cookie capture.
