## Как продолжать работу после удаления чата

1. Подключить GitHub к новой беседе/рабочему окружению с доступом к репозиторию \`wwwrocket065-eng/Hello_World_\`.
2. Открыть ветку \`glassstudy-filament-ci\`, прочесть \`glassstudy/PROJECT_CONTEXT.md\`, \`glassstudy/RELEASE_PLAYBOOK.md\` и \`glassstudy/DEV_NOTES.md\`.
3. Сверить HEAD ветки, \`glassstudy/gradle.properties\`, \`glassstudy/updates/v2/latest.json\` и последние GitHub Actions runs. **Не считать версии или статус из этой памятки вечными.**
4. Рабочая инструкция: правка файлов через GitHub (commit в эту ветку), автоматическая сборка в GitHub Actions, получение unsigned APK, подпись **исходным** сертификатом за пределами GitHub, проверка подписи и выдача. Небольшие правки ресурсов — только подписанный \`.pupdate\`.
5. Не начинать проект заново; не откатывать исправленные функции без явного указания пользователя. Добавлять причины сбоев и решения в DEV_NOTES.

## Проекты

### GlassStudy 3D LAB — текущий приоритет
- Нативное Android/Kotlin приложение, рендер Google Filament + gltfio и GLB, отдельный patch manager.
- Исходники/CI: \`glassstudy/\` в \`glassstudy-filament-ci\`.
- Развёрнутый конспект: [glassstudy/PROJECT_CONTEXT.md](glassstudy/PROJECT_CONTEXT.md).
- Выпуск APK и патчей: [glassstudy/RELEASE_PLAYBOOK.md](glassstudy/RELEASE_PLAYBOOK.md).
- Ошибки/уроки: [glassstudy/DEV_NOTES.md](glassstudy/DEV_NOTES.md).
- Требования: UI из старой GlassStudy v0.1.22; **нет** кнопок «Применить» и «Экспорт»; верхние 4 иконки, слева диагностика-чип, бирюзово-графитовый стиль; максимально широкая патчируемость UI/ресурсов через маленькие проверенные \`.pupdate\`; не затрагивать рендер без отдельной просьбы.
- Последнее пользовательское требование: кастомная диагностика в стиле v0.1.22, полупрозрачная рамка, тёмно-синий текстовый блок, шапка только «Диагностика» и маленькая иконка копирования; закрытие по тапу снаружи/повторному тапу на чип/нажатию другой кнопки (которая должна выполнить действие), без нижних «ОК/КОПИРОВАТЬ». Исходники в версии 0.2.26 содержат PopupWindow, но установка на устройство требует проверки.

### Hello_World_ — отдельная Android-игра
- Проект модульных пушек, режимов Classic/Noita/Roguelike, Noita-эффектов и баланса по Magicraft. Рабочие версии из прежней истории 0.191—0.196. Инвентарь 16, обязательный модуль «Снаряд»; DPS-манекены, объединение/удаление, лазерные и статусные эффекты, графики CPU/GPU/RAM в диагностике.
- **Критично:** обновления APK должны быть подписаны исходным ключом игры. Ошибочный v0.196_FRESH_INSTALL был подписан другим ключом и не обновлял v0.195. Исходную подпись проверять по предыдущему работающему APK, не использовать новую при каждой сборке. Приватный ключ — вне GitHub, в защищённом хранилище пользователя.
- Перед работой найти актуальный проект/ветку и DEV_NOTES; не считать GlassStudy и Hello_World_ одним APK, несмотря на имя общего репозитория.

### Panspermia — сферический клеточный автомат
- Android/WebGL проект, B3/S23 на куб-сфере, цель: корректные 8 соседей через швы, равномерное отображение круглых клеток, NASA/процедурный 360° звёздный скайбокс, масштаб/жесты, производительность миллионов клеток.
- Из истории: v1.9.25, GPU/WebGL1, упаковано 16 клеток в RGBA пиксель, лимит текстуры 8192. Сложности: низкий FPS, скайбокс со швами/растянутыми звёздами, автообновление и диагностика.
- Требование: не ломать запуск ради автообновления; отчёт об ошибке с кнопкой копирования; маленькие патчи, DEV_NOTES.

## Сквозные правила работы

- Пользователь предпочитает короткие отчёты о прогрессе, результаты в виде **реальных рабочих APK/.pupdate**, а не обещаний, картинок/макетов или бесконечных повторений одной проблемы.
- Перед выдачей: исходники → статические тесты → компиляция → подпись исходным сертификатом → проверка подписи → проверка содержимого/версии → ссылка на реально существующий файл. Компиляция **не означает** проверку на устройстве.
- Если доступных инструментов/ключа не хватает, сообщить конкретно что недоступно и где остановились; не заявлять «готово», пока артефакт не проверен.
- Для будущей беседы: запросить этот документ по URL/имени, затем сверить GitHub HEAD. Копию хранить также в ChatGPT Library (вне чата). Память ChatGPT может меняться/удаляться вместе с источниками, поэтому настоящий источник — GitHub + отдельная копия пользователя.

## Безопасность и приватность
НЕ помещать в публичный репозиторий закрытые APK/patch signing keys, пароли, ключевые хранилища P12/JKS, токены, пользовательские файлы или произвольные скриншоты. Любые отпечатки публичного сертификата не являются закрытым ключом, но проверять их актуальность.
